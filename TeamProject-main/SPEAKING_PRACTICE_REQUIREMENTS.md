# 口說練習功能需求文件

## 功能概述
新增口說練習功能，讓學生能夠進行英語口說練習，並獲得AI即時回饋和評估。

## 入口設置
在首頁 `templates/index.html` 中已有按鈕：
```html
<a href="/vocabulary_learning/low" class="btn feature-btn mb-2">口說練習</a>
```

## 12個口說主題

| 主題編號 | 主題 | 情境簡述 |
|---------|------|----------|
| 1 | Introducing Yourself | 學生彼此初次見面，自我介紹名字、年級、興趣 |
| 2 | Ordering Food | 在速食店或餐廳點餐，含點餐、加點、結帳 |
| 3 | Asking for Directions | 在街上問路，如問怎麼走到圖書館或捷運站 |
| 4 | At the Supermarket | 問價錢、詢問商品在哪裡、結帳互動 |
| 5 | Making an Appointment | 跟醫院、牙醫、理髮店預約時間 |
| 6 | Shopping for Clothes | 在服飾店選衣服、詢問尺寸、試穿與付款 |
| 7 | At the Doctor's Office | 說明身體不適的症狀，醫師給建議 |
| 8 | Talking about Daily Routines | 描述平日作息，例如幾點起床、上學、做功課等 |
| 9 | Asking for Help | 在校園裡請老師/同學幫忙找東西、搬東西、解釋問題 |
| 10 | Making Invitations | 邀請朋友參加生日派對、看電影、去公園等 |
| 11 | Talking about Hobbies | 描述自己的興趣，例如打球、畫畫、聽音樂等 |
| 12 | Talking about the Weather | 今天的天氣如何、適合做什麼活動（可延伸到旅遊） |

## 功能流程

### 主要功能
1. **出題系統**：AI根據主題和難度出一題
2. **語音輸入**：使用者用麥克風回答問題
3. **AI優化**：AI優化使用者的語句
4. **重錄練習**：讓使用者重新錄音看是否正確
5. **評語回饋**：給出中英文評語
6. **對話記錄**：保留此次對話記錄

### 介面設計
- **聊天室風格**：類似即時通訊的對話介面
- **下拉選單**：選擇CEFR難度等級（需簡易注記難度說明）
- **主題框**：12個主題的選擇按鈕
- **每個主題預設10個大方向**：提供給LangChain出題參考

### 音訊處理
- **AI語音播放**：每句AI生成的內容都要播放英文語音
- **中文不播放**：中文內容不需要語音
- **評語播放**：評語只播放英文部分
- **重播功能**：使用者可以按按鈕重新播放
- **音檔保留**：使用者的錄音檔案要保留，讓他們可以自己聽

### CEFR難度等級
需要實現以下等級並提供簡易說明：
- **A1 (初級入門)**：基礎詞彙，簡單句型
- **A2 (初級進階)**：日常對話，基本時態  
- **B1 (中級入門)**：流暢對話，複雜表達

## 貼心功能設計

### 建議新增功能
1. **進度追蹤**：記錄每個主題的練習次數和進步情況
2. **發音評分**：針對發音準確度給予評分
3. **詞彙提示**：在對話中提供關鍵詞彙提示
4. **情境模擬**：每個主題提供多種真實情境
5. **學習報告**：定期生成學習進度報告
6. **收藏功能**：讓學生收藏優秀的對話範例
7. **同儕比較**：匿名的班級平均分數比較
8. **每日挑戰**：每天推薦一個練習主題
9. **語音速度調整**：可調整AI語音播放速度
10. **離線練習**：部分功能支援離線使用

## 資料庫設計

### 新增資料表
1. **SpeakingSession**：口說練習會話記錄
2. **SpeakingExchange**：對話交換記錄
3. **SpeakingProgress**：進度追蹤

### 資料欄位
- 使用者ID、主題ID、難度等級
- 問題內容、回答內容、評估結果
- 音檔路徑、時間戳記
- 各項評分（語法、詞彙、流暢度等）

## 注意事項

1. **風格一致性**：需要與其他頁面保持相同的設計風格
2. **實際功能**：確保所有功能都能正常運作，不只是展示
3. **使用者體驗**：介面要直觀易用，適合國小學生
4. **效能考量**：音檔處理和AI回應要有適當的載入提示
5. **錯誤處理**：需要完善的錯誤處理機制
6. **資料安全**：保護使用者的語音資料和學習記錄
