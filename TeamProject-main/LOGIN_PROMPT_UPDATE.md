# 登入提示功能更新

## 問題描述

當使用者尚未登入時嘗試開始測驗，會收到不友好的錯誤信息："開始測驗失敗：User not authenticated"。

## 解決方案

### 1. 後端API改進

#### 修改錯誤響應格式
所有需要登入的API端點現在返回更友好的錯誤信息：

```json
{
    "error": "User not authenticated",
    "message": "測驗前請登入帳號以保存紀錄",
    "redirect": "/login"
}
```

#### 修改的API端點
- `POST /api/start_quiz`：測驗前請登入帳號以保存紀錄
- `GET /api/quiz_status`：請登入帳號以查看測驗狀態
- `GET /api/get_quiz_question`：請登入帳號以繼續測驗
- `POST /api/submit_quiz_answer`：請登入帳號以提交答案
- `POST /api/complete_quiz`：請登入帳號以完成測驗
- `GET /api/lesson_progress`：請登入帳號以查看學習進度
- `POST /api/update_word_progress`：請登入帳號以保存學習進度

### 2. 前端UI改進

#### 登入提示模態框
- 美觀的模態框設計，包含圖標和漸變背景
- 清晰的提示信息
- 兩個操作按鈕：「前往登入」和「取消」
- 支持點擊背景關閉

#### 狀態保存功能
- 自動保存當前頁面信息到 sessionStorage
- 保存當前主題和課程信息
- 登入後可以返回到原來的位置

#### 統一錯誤處理
- 新增 `handleApiError()` 函數統一處理401錯誤
- 所有API調用都使用統一的錯誤處理機制

### 3. 用戶體驗改進

#### 未登入狀態的優雅處理
- 學習進度載入失敗時使用空數據，不影響頁面顯示
- 測驗狀態檢查失敗時使用預設狀態
- 單字學習進度更新失敗時靜默處理

#### 響應式設計
- 登入提示模態框支持手機端顯示
- 在小屏幕設備上按鈕垂直排列

## 文件修改清單

### 後端文件
- `app.py`：修改所有需要登入的API端點的錯誤響應

### 前端文件
- `static/js/vocabulary_learning.js`：
  - 添加 `showLoginPrompt()` 函數
  - 添加 `handleApiError()` 統一錯誤處理函數
  - 修改所有API調用的錯誤處理
  - 改進未登入狀態的數據載入邏輯

- `static/css/vocabulary_learning.css`：
  - 添加登入提示模態框樣式
  - 支持響應式設計
  - 添加動畫效果

## 使用流程

### 未登入用戶嘗試測驗
1. 用戶點擊「開始測驗」
2. 系統檢測到未登入狀態
3. 顯示友好的登入提示模態框
4. 用戶可選擇：
   - 點擊「前往登入」：跳轉到登入頁面
   - 點擊「取消」：關閉提示，繼續瀏覽

### 狀態保存與恢復
1. 系統自動保存當前位置信息
2. 用戶登入後可以返回原來的頁面
3. 保持學習的連續性

## 樣式特色

### 模態框設計
- 深色半透明背景遮罩
- 白色/深色主題適配的模態框
- 藍色漸變標題欄
- 圓角設計和陰影效果
- 平滑的淡入和滑入動畫

### 按鈕設計
- 主要按鈕：藍色漸變，懸停時上移效果
- 次要按鈕：灰色，懸停時變深
- 手機端自適應為全寬度按鈕

## 測試建議

### 功能測試
1. **未登入測驗測試**：
   - 未登入狀態下點擊開始測驗
   - 驗證是否顯示友好提示
   - 測試跳轉到登入頁面功能

2. **狀態保存測試**：
   - 在特定課程頁面嘗試測驗
   - 登入後檢查是否返回原頁面

3. **響應式測試**：
   - 在不同屏幕尺寸下測試模態框顯示
   - 驗證手機端的按鈕佈局

### 兼容性測試
1. **瀏覽器兼容性**：測試主流瀏覽器的顯示效果
2. **深色模式**：驗證深色主題下的樣式
3. **動畫效果**：確認動畫在不同設備上的流暢性

## 注意事項

- 登入提示只在401錯誤時顯示
- 其他錯誤仍使用原有的alert提示
- 未登入狀態下的數據載入不會影響頁面正常顯示
- sessionStorage用於狀態保存，關閉瀏覽器後會清除
