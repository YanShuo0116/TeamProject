# AI English Learning Platform - Developer Guide

## Project Overview

This is a comprehensive AI-powered English learning platform designed for elementary school students, built with Flask and featuring advanced AI integration for personalized learning experiences.

### Core Technologies
- **Backend**: Flask (Python)
- **Database**: SQLite with SQLAlchemy ORM
- **AI Integration**: Google Gemini API with multi-key load balancing
- **Authentication**: Flask-Login
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Audio**: gTTS (Google Text-to-Speech)
- **Image API**: Pexels API
- **Tunneling**: ngrok for public access

### Key Features
- Vocabulary learning with images and audio
- AI-powered composition feedback
- Real-time translation with voice synthesis
- Quiz system with 3 question types
- Progress tracking and analytics
- Admin dashboard with API monitoring
- Multi-API load balancing for reliability

## Database Schema

### Core Models
- **User** - User accounts with role-based access (user/admin)
- **Vocabulary** - Word database with themes and lessons
- **VocabularyProgress** - Individual word learning progress
- **LessonProgress** - Course completion tracking
- **QuizAttempt** - Quiz sessions with status tracking
- **QuizQuestion** - Individual quiz questions and answers
- **Composition** - Essay submissions with AI feedback
- **TranslationRecord** - Translation history and caching
- **LearningRecord** - General activity logging
- **AdminLog** - Admin action auditing

### Key Relationships
- Users have many learning records, compositions, quiz attempts
- Vocabulary words belong to themes/lessons
- Quiz attempts contain multiple questions
- Progress tracking links users to vocabulary items

## Development Setup

### Initial Setup
```bash
# Install dependencies
pip install -r requirements.txt

# Initialize database
python database_setup.py

# Configure API keys in api_config.json
# Set ngrok token in app.py (line 25)

# Run application
python app.py
```

### Default Admin Account
- Username: `admin`
- Password: `admin`
- Access admin dashboard at `/admin/dashboard`

Edit `api_config.json` to add your Gemini API keys:
```json

  "api_keys": ["key1", "key2", "key3", "key4", "key5"],
  "settings": {
    "max_retries": 5,
    "retry_delay": 1,
    "failure_threshold": 3,
    "reset_interval_hours": 1
  }
}
```

## Development Best Practices

### Code Organization
- Use Flask blueprints for modular functionality
- Keep business logic in separate functions
- Use SQLAlchemy models for all database operations
- Implement proper error handling with try-catch blocks

### API Development
- All API endpoints return JSON responses
- Use consistent error response format:
  ```json
  {
    "error": "error_code",
    "message": "User-friendly message",
    "redirect": "/login" // optional
  }
  ```
- Implement authentication checks for protected endpoints
- Use the SafeGenerativeModel for AI API calls

### Frontend Development
- Use vanilla JavaScript with async/await for API calls
- Implement proper loading states and error handling
- Follow responsive design principles
- Use CSS custom properties for theming
- Cache resources for performance (images, audio)

### Database Operations
- Always use database transactions for multi-step operations
- Implement proper foreign key relationships
- Use database migrations for schema changes
- Regular cleanup of temporary data (translations, old records)

### Security Considerations
- Never expose API keys in frontend code
- Use Flask-Login for session management
- Implement role-based access control
- Validate all user inputs
- Use HTTPS in production (ngrok provides this)

## Performance Optimization

### Implemented Optimizations
- **Image Caching**: Pexels images cached to avoid repeated API calls
- **Audio Caching**: TTS files cached and reused
- **Background Preloading**: Common resources loaded at startup
- **API Load Balancing**: 5-key rotation prevents rate limiting
- **Database Indexing**: Proper indexes on frequently queried fields

### Monitoring
- Admin dashboard shows API usage statistics
- Real-time success rates and response times
- Failed request tracking and automatic recovery

## Common Issues & Solutions

### API Rate Limiting
- System automatically switches between 5 API keys
- Failed keys are temporarily disabled and auto-recovered
- Monitor usage in admin dashboard

### Audio Generation Issues
- Check TTS service availability
- Verify audio file permissions
- Clear audio cache if corrupted: `rm audio_files/word_*.mp3`

### Database Corruption
- Backup database regularly
- Use migration scripts for schema changes
- Re-initialize with `python database_setup.py` if needed

### ngrok Connection Issues
- Verify ngrok auth token
- Check firewall settings
- Use alternative tunneling service if needed
